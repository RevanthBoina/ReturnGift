When the user asks to generate/create an image or picture, route it to an external
AI service installed on the device. Gemini is the default when the user names it.
This task is SUPPORTED — never refuse it.

1. **Service choice** → if the user did not name a service, call
   ask_user(question="Which AI should generate the image?", choices="Gemini; ChatGPT; Copilot")
   and use the answer. If Gemini is chosen, continue below; otherwise drive that app
   analogously.
2. **open_app** → open_app(package_name="com.google.android.apps.bard", wait_after=2500).
   If it is not installed, try the Gemini site in the browser instead
   (open_app(package_name="com.android.chrome") then navigate to gemini.google.com).
3. **input_text** → focus the prompt field and type the user's image prompt, then submit
   (tap the Send control or system_key(key="enter")). Repeat/extend the prompt until the
   ask is unambiguous if needed.
4. **wait** → poll get_screen_info with wait(duration_ms=3000) until the generated image
   is actually present in the response (network generation can take 10–30 s — retry
   within the same session on lag).
5. **Download control (REQUIRED)** → tap the app's OWN Download/Save control for the
   generated image (the "Download full size"/download icon under the image). NEVER
   substitute take_screenshot for this step — only fall back to
   take_screenshot(save_to_vault=true) when the app provably offers NO download control.
6. **import_download** → import_download(name_hint="<keyword from prompt>") to copy the
   downloaded file from system Downloads into the vault (images/…).
7. **finish** → finish(summary="Image generated by Gemini and saved to vault: images/<file>
   (visible in the Vault screen)."). If the download/import failed, say so honestly.

If Gemini asks to sign in, ask the user to sign in first (auth walls are never bypassed).
