# ReturnGift — Strategy

→ This file previously contained ReturnGift's public acquisition/moat strategy. That content has been removed — it described a product ReturnGift is not building and a go-to-market path ReturnGift is not pursuing.

ReturnGift is a private/internal project. The strategic direction is:

- Single on-device foundation model, no cloud fallback
- LoRA-based Action Skills for task-sequence coverage
- Device-resident harness: runs entirely inside the installed APK
- No public release, no community OSS, no acquisition targeting

For architecture decisions, see `README.md` and `ARCHITECTURE_RECONSTRUCTION.md`.
